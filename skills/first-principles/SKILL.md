# 第一性原理

## 用途

运用第一性原理思维：通过定义明确问题，将复杂问题解构至公理；明确当前问题的前提，再基于公理和前提重新推演，得到推论，进而解释问题、制定原则或构建解决方案。

## 概念

| 概念 | 本技能中的含义 |
| --- | --- |
| 定义 | 明确所讨论的对象和术语的含义。 |
| 公理 | 在所选体系中直接作为推演起点接受、无需在该体系内证明的命题。采用依据和适用范围需要明确。 |
| 前提 | 除已单独列出的公理外，当前推演采用的已知事实、附加条件或暂定假设。 |
| 推演 | 按有效的推理规则，从公理和前提得到推论的过程。 |
| 推论 | 通过推演得到的命题，其成立依赖所用的公理和前提。 |

使用这些概念时保持含义一致。需要引入其他概念时，先明确其含义和必要性。

## 思维方式

### 明确定义与前提

确定当前问题、所讨论的对象、关键术语和适用条件。涉及实际系统行为的前提，以相关代码、文档或观测核对；未经确认的内容标为暂定假设。只有缺失的信息会改变分析时，才向用户澄清。

### 解构至公理

追问已有判断和规则依据什么成立。能够继续推导的内容，追溯其所用的公理和前提；已能由公理和前提推出的内容，作为推论呈现。

解构深度以当前问题范围为界。说明采用哪些公理、依据是什么、适用于哪里。将业务约束作为公理时，明确它是当前业务约定；依据不足的判断保留为暂定前提，进行条件式推演。

### 从公理重新推演

结合当前前提，重新推演得到回答问题所需的推论。引入额外前提时明确说明；一个推论依赖暂定假设时，保留这个条件。

据此解释问题、制定原则或构建方案。区分由推演得到的必要要求，以及满足这些要求的具体实现；比较实现时，说明选择还依赖哪些前提。

### 检验推论

检查推论是否确实由所列公理和前提得到，是否暗含额外前提、混用了定义，或存在适用范围内的反例。出现矛盾时，回查定义、公理、前提和推演，并修正受影响的内容。

## 表达要求

1. **优先呈现公理**：明确当前问题采用哪些公理，以及它们的适用范围。
2. **呈现典型的核心推论**：选择具有代表性、直接帮助理解或判断当前问题的推论，展示这些公理能够解释什么、决定什么。
3. **通过例子解释推演**：结合具体例子中的定义和前提，展示如何从公理推演得到推论，使读者理解当前问题范围内的第一性原理推演，并能用于思考同类问题。

例子承担解释作用；推论是否成立，仍取决于公理、前提和推演。明确区分示意例子与实际观测。

必要的定义和影响推论成立的前提，随相关内容说明。共享同一公理的推论围绕该公理组织，同一依据解释一次；段落和篇幅按当前问题自然展开。

需要区分公理、前提与推论，或校准具体表达方式时，阅读[示例与概念来源](references/example-and-sources.md)。
